    EDA — Stroke Prediction¶

    Luca Santana Feltrin · Eduardo Takei Yaginuma · Gabriel Fernando Missaka Mendes

    Insper · Artificial Neural Networks and Deep Learning · 2026.2

    This report asks which demographic and recorded health features are associated with the observed stroke label and how to prepare them for a future neural network classification project. It does not train a predictive model. All exploratory analyses after the split use training rows only; test rows are used for split accounting and the required transformation checks.

    0. Proposal¶

    The team selected classification with the public, tabular Stroke Prediction Dataset, published by fedesoriano. The team confirms instructor approval of this dataset. The team repository is LucaFeltrin14/ann-dl.

    The CSV contains 5,110 rows × 12 columns: an identifier, the target, and 10 predictors (3 numerical and 7 categorical). It meets the minimum of 1,000 instances and five mixed-type features. The same dataset will be retained for the classification deliverable.

    Motivation: Mixed demographic and health measurements provide a useful test of neural network preparation: categorical encodings, different numerical scales, missing measurements and a rare positive class coexist in a compact dataset. Studying these properties first allows the later modeling choices to be grounded in evidence.

    First risk: Only 249/5,110 = 4.87% of rows have stroke=1; accuracy alone could conceal failure to detect positives. The original sampling frame, measurement timing and collection protocol are not established by the public description, so clinical generalization and prospective prediction cannot be claimed from this file.

    1. Initial inspection¶

    A. Data dictionary¶

    Source and unit of observation: Each row is a patient record in the published CSV, with a unique id. The public description does not establish the hospital, country, collection date, representative sampling or whether measurements precede the stroke label. This is an analysis of the recorded label, not evidence of future incident stroke prediction.

    D. Train and test¶

    Use train_test_split(..., test_size=0.2, stratify=stroke, random_state=42): 4,088 training records (3,889 negative, 199 positive) and 1,022 test records (972 negative, 50 positive). Both classes appear in both sets; Table 3 gives the resulting percentages. The IDs are saved in results/split_ids.csv and checked for disjointness and complete coverage of the 5,110 original records. No row was removed before the split.

    The absence of dates rules out a defensible temporal split with this file. There are no repeated IDs to group; if repeated-patient information becomes available, the split must be revisited. All medians, scales, category vocabularies, outlier fences, correlations and projections below come from training data. The test set is not used to choose transformations, parameters or figures. For future model selection, create validation folds within these training IDs and refit the complete pipeline inside every fold; reserve these test IDs for final evaluation.

    4. Preprocessing¶

    A. Strategies¶

    These choices prepare the features for a neural network without consuming the test set.

    Missing values: BMI is the only column with empty cells (Table 2). Training BMI missingness is 18.59% for stroke=1 versus 3.42% for stroke=0. Dropping incomplete rows could disproportionately remove positives. Impute each numerical feature with its training median, and retain an explicit 0/1 BMI-missing indicator so the absence is not silently equated to an observed median. This pattern may reflect collection practice, so the indicator is also a leakage/generalization risk to review in future modeling. Categorical empty cells, if encountered, use __MISSING__; the observed Unknown smoking category is retained separately. No missing value is filled using the target.

    Outliers: Table 11 applies training-only 1.5×IQR fences to observed values. There are 569 distinct flagged training rows (some features can flag the same row). The chosen strategy removes 0 rows and clips 0 values: an IQR flag does not establish an erroneous health measurement, and adult BMI thresholds should not be imposed on a mixed-age sample. Retain the extremes and document their influence; do not delete a minority patient because of an unusual feature. Robust scaling limits the effect of extremes on fitted location and scale, although it does not bound the transformed values or eliminate their effect on PCA.

    Table 11. Training outlier fences and counts.

    feature lower_fence upper_fence flagged flagged_pct
    age -26.500 113.500 0 0.000
    avg_glucose_level 21.985 169.525 503 12.304
    bmi 9.350 47.350 90 2.202

    Encoding: The seven nominal predictors (including hypertension and heart disease) have 2–5 categories each (Table 5), making one-hot encoding appropriate without a large vocabulary. Use drop=None: there is no reference-category constraint for a neural network, and observed categories remain explicit. OneHotEncoder(handle_unknown="ignore") maps an unseen category to an all-zero block and preserves the feature count. This is explicitly checked using a synthetic unseen gender; the real test set need not contain an unseen category to test this contract. Do not target-encode, resample, or balance before the split.

    Scaling: The training ranges differ: age 0.08–82.00, glucose 55.12–271.74, and BMI 10.30–97.60 (Table 4), while categorical indicators lie in [0,1]. The observed glucose/BMI right tails and Table 11 motivate RobustScaler, subtracting the training median and dividing by the training IQR after imputation. It helps numerical conditioning without fitting extreme-sensitive mean/variance parameters. One-hot columns and the missingness indicator remain 0/1; scaling every rare binary column to unit variance would amplify rare categories. No additional scaling is fitted on test.

    B. Dimensionality reduction¶

    All projections use the same 4,088 training rows and 24 pipeline-output features. Neither stroke nor id enters their fitting; target values are used only for coloring. There is no subsampling for fitting. Euclidean distance is applied to robust-scaled numerical features plus one-hot categories and the BMI-missing indicator. This mixed representation weights continuous and categorical blocks according to this preprocessing choice; its geometry is not a clinical distance. Redundant one-hot blocks can also create zero-variance PCA directions.

    PCA: Fit full SVD on the transformed train only. PC1 explains 29.25%, PC2 explains 17.40%, and together they explain 46.65%; 10 components reach 90% cumulative variance. The two displayed components therefore cannot represent all predictive information. PCA centers its input internally; no target enters the decomposition.

PC1 is dominated by glucose (+0.8684); PC2 contrasts BMI (+0.5612) and age (+0.3659) with glucose (-0.4818).     5. Synthesis¶

    Findings and risks for the modeling team¶

    Finding and evidence Modeling consequence / handling plan
    Minority class: 249 cases, 4.87% (Table 3; Figure 1) Use stratified validation within training. Report PR-AUC, recall, precision and confusion counts; choose thresholds using validation. Fit class weights or any resampling inside training folds only.
    Age structure and unadjusted disease/category associations overlap (Tables 7–10; Figures 6–9) Keep the features, investigate confounding and subgroup behavior during validation; avoid causal or diagnostic claims from EDA.
    BMI missingness is more frequent among positives (Table 2; section 4A) Keep median imputation and the indicator; compare validation behavior with/without the indicator and investigate recording-time leakage.
    Glucose and BMI have right tails; 569 rows are flagged by IQR (Tables 4 and 11; Figure 2) Retain the rows, use robust scaling and inspect training-fold sensitivity to extreme values; never select cutoffs from test outcomes.
    Rare categories and unavailable smoking information (Table 5; Figure 3) Preserve documented categories; handle new categories explicitly and monitor their frequency. One training record cannot support a gender-specific conclusion.
    Strongest numerical pair is moderate, not redundant (Table 6; Figures 4–5) Keep all three numerical predictors; do not turn an exploratory rank correlation into automatic feature selection.
    PCA loses information and nonlinear maps vary with settings (Figures 10–12; Tables 13–14) Use projections to inspect geometry, keep the full pipeline features for modeling, and evaluate any later dimension reduction within validation folds.
    Collection provenance and feature timing are not established (sections 0 and 1) Treat the task as classification of recorded labels. Obtain provenance and longitudinal timing before claiming future risk prediction or clinical validity.

def build_preprocessor() -> Pipeline:
    """Return a fresh Pipeline; output is a dense, finite numeric matrix.

    The explicit BMI indicator is never scaled (its values stay 0/1). Missing
    categories use a distinct sentinel; the literal smoking category Unknown
    remains an observed category. Unknown categories at transform time produce
    an all-zero one-hot block and never trigger fitting on the held-out rows.
    """
    columns = ColumnTransformer([
        ("num", Pipeline([
            ("impute", SimpleImputer(strategy="median", keep_empty_features=True)),
            ("scale", RobustScaler(quantile_range=(25, 75))),
        ]), NUMERIC_FEATURES),
        ("bmi_missing", MissingIndicator(features="all", error_on_new=False), ["bmi"]),
        ("cat", Pipeline([
            ("impute", SimpleImputer(strategy="constant", fill_value="__MISSING__")),
            ("encode", OneHotEncoder(handle_unknown="ignore", sparse_output=False,
                                     dtype=float, drop=None)),
        ]), CATEGORICAL_FEATURES),
    ], remainder="drop", verbose_feature_names_out=True)
    return Pipeline([("columns", columns)])

def save(fig, number, slug, title):
    fig.suptitle(f"Figure {number}. {title}", fontsize=15, fontweight="bold")

def grouped_numeric(train, by):
    rows = []
    for feature in NUM:
        for category, group in train.groupby(by, observed=True, sort=True):
            x = group[feature].dropna()
            rows.append(dict(feature=feature, group=str(category), count=len(x),
                             median=x.median(), q1=x.quantile(.25), q3=x.quantile(.75),
                             iqr=x.quantile(.75)-x.quantile(.25)))
    return pd.DataFrame(rows)


def projection_plot(ax, xy, y, title, names=("Dimension 1 (arbitrary units)", "Dimension 2 (arbitrary units)")):
    for value in [0, 1]:
        mask = y == value
        ax.scatter(xy[mask, 0], xy[mask, 1], s=9 if value == 0 else 19,
                   color=COLORS[value], alpha=.28 if value == 0 else .85,
                   label=f"{LABELS[value]} · n={mask.sum():,}", rasterized=True,
                   edgecolors="none")
    ax.set(title=title, xlabel=names[0], ylabel=names[1])
    ax.legend(fontsize=8)
